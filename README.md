# Mini CRM Airtable Lead Management

A lightweight CRM for sales and customer care using Airtable.

## Features
- Tables: Leads, Activities, Deals
- Automations: Next-task reminders, follow-up emails
- Dashboard: Daily touches, win rate, time to first contact
- Interfaces for tracking and reporting

## Usage
1. Duplicate the Airtable base (link here if public)
2. Import CSVs from `/data` for sample data
3. Customize fields as needed
4. Set up automations (see `/automations/sample_automation.md`)

## Data
Put all reference CSVs in the `/data` folder.

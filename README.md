# Mini-CRM-for-Lead-Management (Airtable, 2025) 
A lightweight CRM built in Airtable for sales and customer care.  
Features:
- Tables: Leads, Activities, Deals
- Automations: Next-task reminders, follow-up emails
- Dashboard: Daily touches, win rate, time to first contact (reduced by X%)
- Interfaces for easy tracking and reporting

## Usage
1. Duplicate the Airtable base (link in repo if public)
2. Customize fields as needed
3. Set up automations for reminders and emails
